# 📊 AI Data Analysis Agent

An AI-powered Data Analysis Agent built using **Streamlit**, **Python**, **Pandas**, **Seaborn**, and **LangChain**. The application allows users to upload CSV or Excel datasets, perform automated Exploratory Data Analysis (EDA), generate insightful visualisations, and ask questions about their data using natural language.

### ✨ Features

* Upload CSV and Excel datasets
* Dataset preview and summary statistics
* Missing value analysis
* Automated EDA with Seaborn visualisations
* Correlation heatmap and trend analysis
* AI-powered chatbot for dataset queries
* Interactive and user-friendly dashboard

### 🛠️ Tech Stack

* Python
* Streamlit
* Pandas
* Matplotlib
* Seaborn
* LangChain
* Hugging Face (TinyLlama)

### 🎯 Objective

To simplify data exploration by combining automated analytics with AI-powered insights, enabling users to understand datasets quickly and make informed decisions.
